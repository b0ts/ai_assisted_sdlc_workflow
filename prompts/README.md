# Prompts

Predefined prompts for each step's chat. Names start with the step number. If a step ever needs more than one prompt, a second number is added (`c01-01-...`, `c01-02-...`).

- [c01-tracking-prompt.md](c01-tracking-prompt.md): Step 1, Tracking (Scrum Master)
- `c02-...`: Feasibility (step 2), and so on

See the [numbering system](../README.md#numbering-system) for the full scheme.

*Prompts for steps 2 through 10 coming soon.*

These two files are not step prompts. They are the informal and formal prompts used to write [Steps, Roles, and Deliverables](../docs/a02-steps-roles-and-deliverables.md), kept as examples for [Prompt Engineering](../docs/a04-prompt-engineering.md). They are saved exactly as written, so they still use the old file names and the nine-step list.

- [example-01-roles-and-deliverables.md](example-01-roles-and-deliverables.md): informal prompt
