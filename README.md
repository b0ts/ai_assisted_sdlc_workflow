# AI-Assisted SDLC Workflow

Documentation and templates for incorporating AI assistance into the software development lifecycle (SDLC).

## Contents

- [`docs/`](docs/) — guidance on where and how AI assistance fits into each phase of the SDLC
- [`templates/`](templates/) — templates to help teams implement the workflow

## Example project

- [RC Park Tour](https://github.com/b0ts/rc_park_tour) — an interactive and printable tour of Rosicrucian Park in San Jose, built using this workflow. Its [`docs/`](https://github.com/b0ts/rc_park_tour/tree/main/docs) folder records how each SDLC phase was carried out.
