## Step guides (b)

Step 1 starts first and stays open while steps 2 through 10 run one after another. Step 6 is similar: it sets up the initial infrastructure, and the DevOps Engineer keeps supporting steps 7 through 10.

1. [Tracking](b01-tracking.md) — Scrum Master (ongoing)
2. [Feasibility](b02-feasibility.md) — Product Manager
3. [Requirements](b03-requirements.md) — Product Manager
4. [Design](b04-design.md) — Software Architect
5. [User Experience](b05-user-experience.md) — UI/UX Designer
6. [Initial Infrastructure](b06-infrastructure.md) — DevOps Engineer (support continues through step 10)
7. [Test Creation](b07-test-creation.md) — SDET
8. [Implementation](b08-implementation.md) — Software Engineer
9. [Release](b09-release.md) — Release Manager
10. [Maintenance](b10-maintenance.md) — SRE / Maintenance Engineer
