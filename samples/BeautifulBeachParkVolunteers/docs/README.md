# Documents

The documents each step produces. Name each file with the d-number of the
template it came from, so files sort in step order and match the workflow
repo's `templates/` folder.

| Example file | Step |
|---|---|
| `d01-01-checklist.md` | 01 Tracking |
| `d02-01-one-pager.md` | 02 Feasibility |
| `d03-01-prd.md` | 03 Requirements |
| `d04-01-spec.md` | 04 Design |
| `d04-02-design-options.md` | 04 Design |
| `d05-01-ui-ux.md` | 05 User Experience |
| `d05-02-style-guide.md` | 05 User Experience |
| `d06-01-infrastructure.md` | 06 Initial Infrastructure |
| `d06-02-infrastructure-options.md` | 06 Initial Infrastructure |
| `d06-03-cost-sign-off.md` | 06 Initial Infrastructure |
| `d07-01-test-plan.md` | 07 Test Creation |
| `d07-02-test-results.md` | 07 Test Creation (continued in 08) |
| `d08-01-implementation-record.md` | 08 Implementation |
| `d08-02-developer-guide.md` | 08 Implementation |
| `d08-03-release-notes.md` | 08 Implementation (finalized in 09) |
| `d09-01-release-plan.md` | 09 Release |
| `d09-02-release-readiness-review.md` | 09 Release |
| `d09-03-release-efficacy.md` | 09 Release |
| `d10-01-maintenance-log.md` | 10 Maintenance (kept up to date while live) |
| `d10-02-maintenance-status-report.md` | 10 Maintenance (one per report; the sample keeps one) |
| `d10-03-next-phase-or-sunset.md` | 10 Maintenance (only when needed) |

Each document is created by running that step's chat with its prompt.
